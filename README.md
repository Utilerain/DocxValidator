# DocxValidator

Валидатор word документа на соответствие стандартам, указанным в дипломах, курсовых работах и тп

## Проверки:
- Поля страницы
- Форматирование текста (шрифт, размер шрифта)
- Форматирование колонтитулов 
- Титульная страница
- Таблицы
- Оглавление
- Наполнение текста на страницу
- Литература и ссылки

## Установка:

1) Клонируйте репозиторий:
```
git clone https://github.com/utilerain/docxvalidator
```
2) Проведите установку через pip:
```
pip install -r requirements.txt
```

3) Запустите, указав свой Word документ
```
python main.py ./docx/doc.docx
```

### Дисклеймер

Данный проект находится в разработке и предназначен для проверки документа для соответствия правилам, указанным в рамках моего колледжа. Для создания правил для проверки использовался ИИ
