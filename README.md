# DocxValidator

Валидатор word документа на соответствие стандартам, указанным в дипломах, курсовых работах и тп

Правила проверки взяты из МДК 04.01 (слайды 196–218: «Требования к оформлению документации»)

## Проверки:
- Поля страницы
- Форматирование текста (шрифт, размер шрифта)
- Форматирование колонтитулов
- Титульная страница
- Таблицы
- Оглавление
- Наполнение текста на страницу
- Литература и ссылки
- Элементы введения (актуальность, объект, предмет, цель, задачи, методы, значимость, структура)
- Вывод в конце параграфа/главы (например: «Таким образом, …»)
- Ссылки на источники: формат [N] / [N, с.M], в конце абзаца перед точкой, наличие на каждой странице теоретического раздела
- Приложения: заголовок по правому краю, шрифт 12 пт, интервал 1, без нумерации страниц
- Рисунки: подпись «Рис. N. Название» по центру, ссылки вида (см.рис. N)
- Таблицы: надпись «Таблица N» справа, название по центру, шрифт и выравнивание в ячейках, «Продолжение таблицы N», ссылки вида (см.табл. N)
- Формулы: выравнивание по центру, нумерация справа, описание до и обозначения после («где: …»)
- Списки: тире/скобка/точка, регистр после маркера, знаки в конце пунктов, отступ текста 1,75 см (2,0 см от 10 пункта)
- Тире и дефисы: в тексте только тире средней длины (–)

## Установка:

1) Клонируйте репозиторий:
```
git clone https://github.com/utilerain/docxvalidator
```
2) Проведите установку через pip:
```
pip install -r requirements.txt
```

3) Запустите, указав свой Word документ
```
python main.py ./docx/doc.docx
```

### Дисклеймер

Данный проект находится в разработке и предназначен для проверки документа на соответствия правилам, указанным в рамках моего колледжа. Для создания правил для проверки использовался ИИ
