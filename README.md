# DocxValidator

Валидатор word документа на соответствие стандартам, указанным в дипломах, курсовых работах и тп

Правила проверки взяты из МДК 04.01 (слайды 196–218: «Требования к оформлению документации»).
Сверка с предоставленной презентацией `оформление.pptx` (23 слайда) и ограничения проверок описаны в [VALIDATION_COVERAGE.md](VALIDATION_COVERAGE.md).

## Проверки:
- Поля страницы
- Обязательная включённая сетка текста (`w:docGrid`) в каждом разделе; отсутствие сетки или выключенный режим — ошибка. Конкретный шаг сетки не задан требованиями
- Форматирование текста (шрифт, размер шрифта, наследование стилей)
- Форматирование колонтитулов и нумерация страниц по секциям: поле `PAGE` в верхних колонтитулах основных секций, отсутствие номеров на титуле, в содержании, в приложении и в нижних колонтитулах
- Титульная страница
- Таблицы
- Оглавление: формат записей, общий правый табулятор номеров страниц, сверка записей с заголовками глав и параграфов
- Наполнение текста на страницу
- Литература и ссылки
- Элементы введения (актуальность, объект, предмет, цель, задачи, методы, значимость, структура)
- Вывод в конце параграфа/главы (например: «Таким образом, …»)
- Ссылки на источники: формат [N] / [N, с.M], в конце абзаца перед точкой, наличие на каждой странице теоретического раздела, сверка номеров с библиографией (несуществующий источник — ошибка; страница у электронного ресурса — предупреждение)
- Приложения: все заголовки по правому краю с последовательными буквами, шрифт 12 пт допустим (не обязателен), интервал 1, без нумерации страниц
- Рисунки: подпись «Рис. N. Название» по центру, ссылки вида (см.рис. N), сквозная нумерация
- Таблицы: надпись «Таблица N» справа, название по центру, шрифт и интервал в ячейках, шапка по центру по горизонтали и вертикали, числовые ячейки по центру / текстовые по левому краю, «Продолжение таблицы N», ссылки вида (см.табл. N)
- Формулы: выравнивание по центру, нумерация справа, описание до и обозначения после («где: …»)
- Списки: набранные вручную и автоматические (нумерация Word): тире/скобка/точка, регистр после маркера, знаки в конце пунктов, отступ текста 1,75 см (2,0 см от 10 пункта)
- Тире и дефисы: в тексте только тире средней длины (–)
- Белая заливка: текст не должен иметь белую заливку фона/выделения (при отображении сетки текст оказывается на белой подложке)

## Установка:

1) Клонируйте репозиторий:
```
git clone https://github.com/utilerain/docxvalidator
```
2) Проведите установку через pip:
```
pip install -r requirements.txt
```

3) Запустите, указав свой Word документ
```
python main.py ./docx/doc.docx
```

## Тесты

Из корня проекта:

```bash
python -m unittest discover -s tests -v
```

Проверка примера (документ не изменяется):

```bash
python main.py docs/test.docx
```

### Тестовая курсовая

`docs/test_coursework.docx` — сгенерированный образец курсовой работы, который
проходит все правила валидатора без нарушений: титульный лист, содержание,
введение с обязательными элементами, главы с выводами, таблица, рисунок,
формула, списки, библиография, приложение и включённая сетка текста.
Пересоздать его можно командой:

```bash
python docs/make_coursework.py
```

Эталонность образца защищена тестами `tests/test_coursework.py`.

Код выхода `1` означает, что найдены нарушения или предупреждения; это не обязательно сбой программы.

### Ограничения

Валидатор проверяет свойства и структуру DOCX, но не воспроизводит верстку Word.
Заполнение страницы, постраничное наличие ссылок и содержательная полнота выводов оцениваются эвристически.
Сетка текста — настройка раздела документа, а не отображение непечатаемых символов или экранных линий сетки.
Подробности: [таблица покрытия требований](VALIDATION_COVERAGE.md).
